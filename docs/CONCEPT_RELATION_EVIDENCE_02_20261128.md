## 跨案例待覆核（不升格）

- **觀測≠控制≠驗收**：WhatsMyAgentDoing 的 Session watcher、Block Buzz 的頻道佇列、Claude-mem 的記憶索引分別屬於不同運作層；狀態可見不證明任務驗收、憑證隔離或治理權限。延續既有 Agent Usage & State Observability 候選，先補強既有 Concept 的範圍與反例。
- **成本證據≠即時路由**：AWS Agent Cost Bench 比較同任務的結果、費用及耗時，可作 capability-cost-routing 的離線選型依據，不能宣稱已執行即時 fallback 或政策路由。
- **執行前安全控制**：Cloudflare OS 的 canReadCollection、stageAction 是具體局部授權／審批契約；Browser Use 本輪保存證據主要是 Agent.run / close，不能由此推論 CDP/REPL 隔離或所有入口安全。兩者不能用相同證據強度判定。
- **工具元件≠完整原理**：Bencho 互動、Coolors 色盤、DaVinci Resolve 後製各自有實作價值；不要求每項資源都證明整套設計系統或 Agent Pipeline。金融資源索引不等於跨案例模式萃取。
- **圖解≠來源事實保真**：Diagram Design、Agent Loop Visualizer 分別有語意圖表及事件觀察證據，仍須區分研究來源溯源、參考圖不變量、實際後端權限。

## 優先待覆核

1. Sandbox Runtime ↔ reversible-privacy-boundary：檔案／網路隔離與本機 mapping、placeholder 還原是不同機制；先核對來源及原始引用緣由，不能互相替代。
2. Agency Agents ↔ heterogeneous-model-review / vendor-agnostic-orchestration：角色文件與多模型交叉驗收、實際任務分派不同；另需具體協調及模型證據。
3. Pixelle Video ↔ episodic-character-asset-consistency / closed-loop-social-content-system：腳本、影音生成路由尚不足證明跨鏡資產版本、發布、平台成效與回饋。
4. Anti-gambling Trader ↔ deterministic-execution-boundary / local-first-sensitive-data-processing：不提供真實下單，及本機介面不等於敏感資料最小化；維持工具原本的研究用途。
5. ToolAnything 的 Registry/Schema/MCPAdapter 可作為 Typed Tool & Output Contracts 的另一個獨立實作候選，與上輪 Pydantic AI、Smolagents 的型別契約對照。先比對 adapter、驗證、錯誤及授權的差異，優先補強既有 agent-native-tool-abstraction / agent-runtime-harness，不立即新增 Concept。

# P8｜十篇速查表直接在頁內學，不必開 GitHub

## 使用者要解決的問題
前一版雖然有學習目標、十個章節、閱讀路線，仍需要點擊「閱讀這一份原始文件」、展開每篇章節，才能取得可用的知識。使用者希望在**單筆收藏詳情**直接快速閱讀、理解、應用。這份資源是內容學習，不是導航目錄。

## 本次改動
- 僅對 `aiposthub-awesome-opensource-ai-cheat-sheets-guide` 的 `learningGuide` 升版到 2。
- 依原始 10 篇 Cheat Sheets，逐章補上 **3 個有判斷價值的精簡重點**，共 30 點；每章保留實際情境、學完可產出的成果，另外補一項不用額外安裝工具就能開始的小練習。
- 取消「必須展開」的教學卡片：十章全部直接列出內容；前面保留五個學習成果與建議順序。
- 不在閱讀順序區放十個重複 GitHub 跳轉；將十份不同來源文件的固定版本網址集中於**頁面最後的選讀／查核區**。要快速學習時完全不需要點擊來源。
- 保留文章原始 URL、上游 Repo、Commit SHA、原始功能／安全說明及所有六種 Entity，不更動其他 269 個 Resource 的顯示。

## 品質界線
- 學習點依照原始章節的決策表、檢核方法、工作契約、測試與安全邊界整理；不照抄整份原文。
- 舉例與「自己試試看」為理解而設計，**不是作者聲稱已執行的真實專案**，也不當作實際測試結果。
- 這是中文速讀筆記，不是完整技術規格或最新法律遵循認證，查核詳細規則時仍可使用頁底的原始來源。

## 驗收
1. 10 章 × 3 個實質重點 = 30 點；每章都有可操作的小練習與原始版本來源。
2. 10 章的學習內容**直接可見**，無需展開、彈窗或外站跳轉。
3. 保留五個成果、四步路線、綜合練習、原始資源與 548 筆正式收藏。
4. 在 375、430、768、1440px 測試無水平溢出，瀏覽器無例外。
5. 資料來源構建、Graph、學習頁與 Playground 原本測試全數 PASS。
6. 合併後單獨核對 Github Pages 的 Catalog JSON、HTML、CSS 與實際遠端 Chromium 內容。
